# ⚡ Chat Mágico - Fandom Harry Potter

Trabajo Práctico grupal de desarrollo web full-stack. Consiste en una aplicación de chat interactiva con personajes del universo de Harry Potter, respuestas automáticas por palabras clave, estados de mensaje en tiempo real y perfil editable.

## 🧙‍♂️ Temática Elegida
**Personajes de Fandom (Harry Potter):** Los contactos son personajes icónicos de la saga (como Harry, Hermione, Snape, Dumbledore, etc.), cada uno con su propio repertorio de respuestas automáticas y palabras clave.
